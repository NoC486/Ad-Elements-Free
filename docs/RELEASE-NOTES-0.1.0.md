# Ad Elements Free v0.1.0

首个公开版本，支持 KOOK 广告元素隐藏。用户已实测 KOOK 隐藏效果正常。

## 下载

- **Ad-Elements-Free-0.1.0-win-x64-setup.exe**：Windows 10/11 x64 安装版，推荐普通用户使用。
- **Ad-Elements-Free-0.1.0-win-x64-portable.zip**：便携版，解压后运行 AdElementsFree.exe。
- **Ad-Elements-Free-0.1.0-source.zip**：对应 v0.1.0 标签的完整项目源码与构建脚本。
- **SHA256SUMS.txt**：上述附件的 SHA-256 校验值。

安装版和便携版均自带 .NET 8 Desktop Runtime，无需另外安装运行时。

## 安装与使用

安装和升级时均可修改目录。首次安装默认优先 `D:\Program Files\Ad Elements Free`，没有 D 盘时选择其他非 C 盘固定磁盘；均不存在时回退到当前用户目录。请选择当前用户有写入权限的位置，安装程序不会自动要求管理员权限。

启动后程序位于右下角系统托盘（可能在隐藏图标中）。打开主窗口并启用 KOOK；如 KOOK 已经运行，请完全退出后从已配置的快捷方式重新启动。

升级前请从托盘退出本程序。卸载前请先关闭 KOOK 开关以恢复快捷方式，再退出；卸载会保留个人设置和恢复记录。

- 原生 WPF 窗口、独立开关、托盘和自定义图标。

- 快捷方式参数幂等添加及恢复、设置持久化、限额日志。
