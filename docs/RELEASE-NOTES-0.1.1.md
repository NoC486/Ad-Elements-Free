# Ad Elements Free v0.1.1

修复 v0.1.0 在 D:\Program Files 等受保护目录安装时出现“Error 5：拒绝访问”的问题。

- 默认“为所有用户安装”，由安装器申请管理员权限；主程序保持普通权限运行。
- 提供“仅为当前用户安装”选项，无需提权，默认使用用户目录。
- 全用户模式仍优先非 C 盘 Program Files；两种模式均可修改目录。
- 安装、升级、卸载说明使用通用客户端表述，不再包含特定客户端名称。
- 提权安装完成后请从快捷方式启动应用，避免继承管理员权限。

下载 setup.exe 安装版，或 portable.zip 便携版。均为 Windows 10/11 x64，自带 .NET 8。

若 v0.1.0 未安装成功，可直接使用本版本。若已经安装，升级时沿用原安装方式与目录；如需切换方式，请先关闭应用内所有客户端开关，再退出并卸载旧版，之后安装新版。设置和恢复记录保留。

升级前从托盘退出本程序；卸载前关闭所有客户端开关以恢复快捷方式。

安装包尚未代码签名。源码、GPL-3.0-only 许可证和 SHA-256 校验文件随版本提供。
