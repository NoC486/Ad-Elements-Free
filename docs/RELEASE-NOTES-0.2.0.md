# Ad Elements Free v0.2.0

## 新功能

- 主窗口右上角和托盘菜单增加“设置”入口。
- 增加可选“开机自启”，默认关闭；开启后随当前 Windows 用户登录在托盘运行，无需管理员权限。
- 增加手动“检查更新”，显示当前版本，发现新版后提供本仓库发布页链接。不自动下载或安装。
- 主窗口底部增加版本、作者 NoC486 和 GitHub 仓库超链接。
- 卸载时仅清理当前卸载用户中、属于本安装路径的自启项；卸载前仍建议在设置中关闭自启。

## 下载和升级

下载 `Ad-Elements-Free-0.2.0-win-x64-setup.exe` 安装版，或 `portable.zip` 便携版。均适用于 Windows 10/11 x64，包含 .NET 8。

升级前从托盘退出旧版，沿用原有安装方式及目录，设置和客户端恢复记录会保留。安装到 Program Files 时请选择“为所有用户安装”并允许 Windows 安装权限请求。仍支持修改目录，默认优先非 C 盘 Program Files。

便携版移动路径后请重新开启自启。如果 Windows 的“启动应用”中禁用过该项，请在那里重新启用。多个 Windows 用户需要分别设置或关闭自启。

## 验证与源码

通过基础/CDP/设置测试、Windows 窗口和快捷方式集成测试，以及隔离安装/卸载验证。自启注册在隔离测试注册表中验证，未修改正式自启开关；完整重启登录需用户实机验收。
