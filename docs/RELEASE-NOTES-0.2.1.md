# Ad Elements Free v0.2.1

## 修复

- 修复部分设备因客户端内部页面端口不同，一直显示等待可验证页面、无法应用规则的问题。
- 从已验证的调试接口读取实际页面地址，支持 `http://localhost:任意有效端口/app/...` 和 `http://127.0.0.1:任意有效端口/app/...`，不再限定页面端口。
- 保留进程身份、调试连接归属及页面路径校验，不扫描其他端口。
- 随包 README 和贡献指南同步使用通用客户端表述。

## 下载与升级

下载 `Ad-Elements-Free-0.2.1-win-x64-setup.exe` 安装版，或 `portable.zip` 便携版。适用于 Windows 10/11 x64，自带 .NET 8。

升级前从托盘退出旧版，沿用原来的安装方式和目录。设置和恢复记录会保留。安装版仍支持自定义目录，默认优先非 C 盘 Program Files。
