# Ad Elements Free v0.3.0

## 新功能

- 安装版和便携版均将规则独立为 `Rules/客户端名称/style.css`，不再内嵌 CSS。
- 设置新增“同步最新规则”：从 GitHub main 分支获取当前软件支持的各客户端规则，不依赖软件版本号。
- 同步前完成下载与检查，替换时保存 `style.css.bak`，成功后让已启用的客户端重新加载规则。受保护目录通过 Windows 授权助手写入，主程序不整体提权。
- 将用户提供的六条最新隐藏规则转换为标准 CSS。
- 安装选项新增默认勾选的“立即运行”，置于默认不勾选的“创建桌面快捷方式”上方；安装结束后打开主窗口。

## 使用

手动编辑 CSS 后关闭再开启对应客户端开关。同步会覆盖本地修改，建议另外保留自定义规则备份。规则同步只能更新已支持客户端的 CSS；新增客户端功能仍需升级软件。

升级前从托盘退出旧版，沿用安装方式和目录。安装版与便携版均为 Windows 10/11 x64，自带 .NET 8。安装包可能覆盖随包 CSS，升级前请备份自定义规则。
