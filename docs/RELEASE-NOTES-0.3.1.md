# Ad Elements Free v0.3.1

- 使用普通权限的非注入式 Windows 窗口通知发现客户端启动，取消空闲时的定时进程扫描。
- 取消页面识别后的固定四秒等待；调试接口启动期间短暂重试，约三十秒仍未就绪则停止。
- 建立调试连接后改用页面事件，同一页面不重复注入，新窗口自动应用，普通刷新保留规则。
- 保留独立 CSS、手动规则同步，以及安装时默认立即运行的行为。
- 修复导航离开受支持页面时的注册脚本清理，关闭功能时也取消尚未触发的页面就绪回调。

窗口通知不注入 DLL、不需要管理员权限，但会筛选当前桌面的相关窗口事件，不承诺绝对零占用。若客户端启动未触发可捕获的窗口事件，请在打开客户端后重新开启对应开关。

已通过 99 项基础检查、隔离 Windows 窗口通知、模拟 CDP 生命周期、JavaScript 规则和隔离安装测试。维护者已反馈实际客户端测试通过；这不代表所有客户端版本和启动方式均已验证。

Windows 10/11 x64，包含 .NET 8 运行时，GPL-3.0-only。安装包未代码签名。
