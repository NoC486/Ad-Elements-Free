Ad Elements Free

Windows 10/11 x64. The .NET 8 Desktop Runtime is included.

Choose installation for all users to install into Program Files.
Windows requests administrator permission for installation only.
The default is D:\Program Files\Ad Elements Free, then other fixed non-C drives.
If none exists, the Windows Program Files directory is used.

Alternatively choose current-user installation without elevation.
This mode defaults to your user Programs folder. Choose a writable location.
Both modes allow changing the installation directory.
No Windows service, driver or startup entry is installed.
Startup is optional and off by default. Enable it later in Settings.
Settings also includes a manual update check using this project's GitHub releases.

After installation, launch the app from its shortcut with normal permissions.
Find Ad Elements Free in the system tray (including hidden icons).
Open its window and enable the supported clients you want to manage.
If a client is already running, follow the status prompt to restart it
using its configured shortcut when needed.

Before upgrading: exit Ad Elements Free using its tray menu.
Use the same installation mode and folder as the existing version.
Before uninstalling: disable startup in Settings and turn OFF all client switches to restore shortcuts,
then exit the app. Existing settings and recovery records are kept.

安装到 Program Files 等受保护目录时，请选择“为所有用户安装”，并允许 Windows 的安装权限请求。
默认优先 D:\Program Files\Ad Elements Free，其次其他非 C 盘固定磁盘。
如果选择“仅为当前用户安装”，无需提权，默认使用当前用户目录；请选择有写入权限的位置。
两种安装方式均允许修改目录。安装完成后，请从快捷方式以普通权限启动程序。
程序默认驻留系统托盘，请展开隐藏图标并打开主窗口，启用需要管理的客户端。
如果目标客户端已经运行，请根据状态提示，必要时退出客户端并从已配置的快捷方式重新启动。
升级前请从托盘退出本程序，并选择与旧版一致的安装方式和目录。
可在主窗口或托盘菜单的“设置”中开启开机自启（默认关闭），或手动检查更新。
卸载前请先在设置中关闭开机自启，并关闭所有客户端开关以恢复快捷方式，再退出程序。
卸载会保留个人设置和恢复记录，不会修改任何目标客户端的安装文件。
